# 리얼티 실호가 수집기 (크롬 확장, MV3)

네이버 부동산에서 **대상 단지의 전용 84㎡ 실매물 호가**를 **사용자 브라우저에서** 수집해
리얼티프라이스 앱(`/api/listings/ingest`)으로 저장합니다.

## 왜 확장인가 (직방은 왜 안 되나)
- 서버(Vercel) IP는 직방·네이버가 데이터센터 IP로 차단(403/429).
- 브라우저 직접 fetch는 CORS 차단.
- **네이버는 페이지와 API가 동일 오리진**이라, 네이버 페이지 안에서 도는 확장/북마클릿은
  CORS·IP차단·토큰을 모두 우회한다(사용자 홈 IP + 페이지 세션 토큰 재사용).

## 설치
1. `chrome://extensions` → 우상단 **개발자 모드** ON
2. **압축해제된 확장 프로그램을 로드** → 이 `extension/` 폴더 선택
3. 확장 아이콘(팝업)에서 **앱 주소(Origin)** 입력 (예: `https://내앱.vercel.app`). 앱에
   `INGEST_SECRET`을 설정했다면 같은 값을 **인제스트 시크릿**에 입력. → **설정 저장**
   - 커스텀 도메인을 쓰면 `manifest.json`의 `host_permissions`에 그 도메인을 추가하세요.

## 사용
### A) 단건(권장·확실) — 사용자 트리거
1. 네이버 부동산에서 대상 단지 페이지 열기: `new.land.naver.com/complexes/{번호}`
2. 우상단 패널에서 **매물목록을 한 번 스크롤/매매탭 클릭**(토큰 확보) → 대상 단지 선택
3. **"이 단지 84㎡ 호가 앱으로 전송"** → 앱 DB 저장(매매/전세 건수 표시)
   - 이때 단지↔앱대상 매핑이 저장돼, 이후 배치에 재사용됩니다.

### B) 배치(실험적) — 팝업 "대상 리스트 전체 수집"
- A로 한 번씩 매핑된 단지들을 백그라운드 탭으로 순회 수집합니다.
- 백그라운드 탭이 토큰을 만들지 못하면 그 단지는 건너뜁니다(A로 보완).

## ⚠️ 법적 고지 (반드시 읽기)
네이버 부동산 매물 DB는 법원이 **DB제작자권리를 인정**했고, 크롤링 재배포에 대해
배상·삭제를 명령한 판례(네이버 vs 다윈중개)가 있습니다.
- 이 도구는 **사용자 본인이 직접 트리거**할 때만, **본인 대상 리스트 범위**에서 동작하도록
  설계됐습니다(무인 타이머 자동수집 없음).
- **대량·상시 자동 수집이나 제3자 재배포는 침해 소지**가 있으니 하지 마세요.
- 상업 서비스의 합법 데이터 축은 **국토부 실거래 + 부동산원 지수(공식 OpenAPI) + KB시세**로
  두고, 네이버 실호가는 **사용자 참조용 보강**으로 격리하세요.
